## What I actually do

Most designers hand off a Figma file. Most engineers can't art-direct. I work both
ends of that handoff, which means the thing that ships looks like the thing that
was designed.

Three years across **fintech, AI and B2B** — brand-led visual systems, product
marketing visuals, product design, and the motion work that makes any of it move.
Then I build it: production React and TypeScript, deployed.

**The through-line is retention.** A 15-second Reel hook, a testimonial cut, the
first paint of a landing page — the craft question is the same one every time. Does
it hold attention, and can you prove that it did?

## The portfolio site is itself the code sample

[**nileshchaturvedi.com**](https://nileshchaturvedi.com) is hand-built, not a
template — and it's the clearest evidence of how I work when nobody is watching.

- **Next.js 16 App Router**, with React Server Components holding the crawlable
  copy so the page has real content before a line of JS executes.
- **A WebGL particle hero** gated on viewport width, network quality, CPU cores
  *and* `prefers-reduced-motion`, then deferred behind `requestIdleCallback` — so a
  phone never downloads the 887 KB chunk.
- **WCAG AA** throughout: full contrast sweep, real focus rings, pinch-zoom intact.
- **767 tests**, 92.6% statement coverage, CI gating every push.
- Every performance figure in its README is measured from an actual build. When an
  audit claimed a contrast token cleared 3:1, I recomputed it and found 2.375:1.

That last habit is the point of all of this. I would rather be correct than
confident.
